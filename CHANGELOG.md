# Changelog

## 0.1.0-alpha.5

- Stream and expand model reasoning in the chat timeline alongside tool calls.
- Inspect chat context, compact long chats, and save an instruction that is included with the first message in a new chat.
- Attach any file type, preview images and text, and reveal saved attachments in File Explorer from chat history.
- Review tasks, command results, and changed files in Overview. Draft diff comments survive a restart.
- Start a chat in a Git worktree or attach a screenshot from a local preview.
- Keep projects with unavailable folders in the sidebar and browse their saved chats.
- Show the full model list in settings, display the Desktop version, and make Save buttons easier to find.
- Fix terminal flicker and attachment thumbnails and removal buttons.

## 0.1.0-alpha.4

First public alpha candidate for Windows x64.

- Added a Windows installer with Node.js and npm.
- First launch starts with language and theme selection. The terminal shows guided steps for consent and GitHub sign-in.
- Chats, project commands, file review, and sequential prompts use the official FreePi CLI.
- The Windows taskbar, shortcuts, and application window use the desktop app icon.

The default CLI version is 0.6.21. Automatic schedules are off by default. The installer is unsigned.
